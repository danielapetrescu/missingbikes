## User stories

As someone who found a bike I want to be able to add it with a photo an location so the owner can recognize and find it
As someone who lost a bike I want to be able to find it in the list

## Detailed requirements per feature

## 1. Add a bike

Required fields

- brand (dropdown, with a button to add a new brand if it is not in the list )
- Color (dropdown )
- Description (optional, limited to 50 characters)
- Photo (mac 4 photo)
- Location (two way of populating: Add the address or press "Use my location" )
- Date (auto-added )
  Validation rule: a bike cannot be added without Brand, Color, at least one Photo, and Location.

## 2. List of bikes

Show picture, brand, location, color and date when was found.
